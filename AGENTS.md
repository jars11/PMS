## Anti-alucinación / evidencia obligatoria

- Nunca afirmes que escribiste o corriste tests sin mostrar:
  1) rutas de archivos
  2) diff o contenido
  3) comando ejecutado
  4) output real
- Si no ejecutaste un comando, decí "no ejecutado".
- Si un test no existe, decí "no existe".
- Está prohibido marcar tareas de testing como completadas sin evidencia.
- En caso de duda, el estado por defecto es BLOQUEADO hasta tener prueba.
